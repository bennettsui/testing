## Claude API Configuration

This project uses the Claude API with the following model:
- **Model Version**: `claude-3-5-sonnet-20250514`

To configure the API:
1. Copy `.env.example` to `.env`
2. Add your Claude API key to the `CLAUDE_API_KEY` field
3. The `CLAUDE_MODEL` is set to `claude-3-5-sonnet-20250514` by default

## Usage

Run the server with:
```bash
node server.js
```
